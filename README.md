# 📊 Sales & Revenue Analysis Dashboard

An interactive Sales & Revenue Analysis Dashboard designed to analyze business sales data, track key performance indicators (KPIs), identify top-performing products, and generate meaningful business insights.

## 🎯 Project Objective

The main objective of this project is to build an interactive dashboard that helps users understand sales performance and revenue trends through visualizations, KPIs, filters, and charts.

## ✨ Key Features

- 📈 Total Sales and Revenue analysis
- 💰 Revenue trend analysis
- 📦 Top-performing product analysis
- 🌍 Region-wise revenue analysis
- 📊 Interactive charts and visualizations
- 🔎 Filters for interactive data analysis
- 📅 Date-based analysis
- 🏷️ Category-wise analysis
- 📋 Detailed product comparison
- 📁 Excel/CSV data import support

## 📌 Dashboard Includes

### KPI Metrics
- Total Revenue
- Total Orders
- Units Sold
- Average Order Value

### Visualizations
- Monthly Revenue Trend
- Top Products by Revenue
- Revenue by Region
- Product Performance Comparison

## 📊 Dataset

The project uses sales transaction data containing information such as:

- Order ID
- Date
- Product
- Category
- Region
- Quantity
- Unit Price
- Discount
- Sales
- Revenue

The included dataset contains **1000 sales records** for dashboard analysis.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `Sales & Revenue Analysis Dashboard.html` in a web browser.
3. Use the available filters and charts to explore the sales data.
4. Excel/CSV data can be imported through the dashboard.
